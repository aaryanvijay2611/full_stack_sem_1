Bash Commands I have Learnt

1. touch

File Creation

The touch command is a simple way to create a new empty file. If the file already exists, it simply updates the file's last modified timestamp instead of changing its content. It's one of the best ways to create a file directly in the terminal.

Syntax: touch filename

Example: touch notes.txt

Output: (no output - the file notes.txt is created silently in the current folder)

2. mkdir

Folder Creation

The mkdir command creates a new, empty folder(directory) at the location you specify.

Syntax: mkdir foldername

Example: mkdir project

Output: (no output - the directory project is created silently in the current folder)

3. cd

Change Directory

The cd command changes the current working directory, moving you into a different folder in the terminal.

Syntax: cd foldername

Example: cd project

Output: (no output - the current directory is changed to project)
